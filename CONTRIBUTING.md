# Contributing

Change a rule only when a first-party source changes or a check is unworkable in practice.

1. Read `AGENTS.md` and `docs/WHY.md`.
2. Update `RULES.yaml` first. That file is the catalogue.
3. Update the matching `rules/*.md` or `style/*.md` file.
4. Update checklists or templates if the check procedure changes.
5. Add the source to `references.md`.
6. Add the path to `llms.txt` if you created a file.

Do not add framework fashion. Do not weaken a blocker to make a generated app pass. Do not paste vendor documentation into this repo.
