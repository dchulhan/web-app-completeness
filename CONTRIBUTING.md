# Contributing

Change a rule only when a first-party source changes or a check is unworkable in practice.

1. Update `RULES.yaml` first. That file is the catalogue.
2. Update the matching `rules/*.md` file.
3. Update checklists or templates if the check procedure changes.
4. Add the source to `references.md`.

Do not add framework fashion. Do not weaken a blocker to make a generated app pass.
