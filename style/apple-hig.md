# Apple Human Interface Guidelines

Canonical: https://developer.apple.com/design/human-interface-guidelines/
Writing: https://developer.apple.com/design/human-interface-guidelines/writing
Web views: https://developer.apple.com/design/human-interface-guidelines/web-views

- Purpose, agency, familiarity, consistency.
- Plain language. Buttons are verbs.
- Language patterns reused. Casing consistent per component type.
- Write for VoiceOver and localisation.
- Do not rebuild Safari in a web view.
- iOS still needs an Add to Home Screen hint. See PWA-006.
