# Google HTML/CSS style guide

Canonical: https://google.github.io/styleguide/htmlcssguide.html

- Include optional elements in shipped examples.
- Lowercase elements and attributes.
- Two-space indent. Spaces, not tabs.
- Semantic elements for meaning. CSS for look.
- alt on images.
- Honour prefers-reduced-motion and prefers-color-scheme when claimed.
