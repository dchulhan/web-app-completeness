# Web style layer

Sources: WCAG 2.2, MDN semantics, GOV.UK content design.

- One page, one job. The h1 states it.
- Links describe the destination.
- Error text names the failure and the next step.
- Semantic HTML. a for navigation, button for actions.
- Buttons are verbs. Same word for the same object.
- Tokens own space, type, radius, and colour roles.
