# Google developer documentation style guide

Canonical: https://developers.google.com/style
Highlights: https://developers.google.com/style/highlights

- Conversational, not frivolous.
- Do not pre-announce unshipped features.
- Descriptive link text. Accessible. Global audience.
- Second person. Active voice.
- Conditions before instructions.
- Sentence case headings. Numbered lists for sequences.
- Serial commas. UI elements in bold when documenting a UI.
- Unambiguous dates. Alt text on figures.

This catalogue uses Queen's English; see style/this-repo.md.
