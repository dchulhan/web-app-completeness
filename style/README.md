# Style guides in this catalogue

This folder does not replace the first-party guides. It says which guide applies where.

| Surface | Guide | File |
| --- | --- | --- |
| This repository's markdown | Google developer documentation highlights + Queen's English | this-repo.md |
| HTML and CSS in templates | Google HTML/CSS Style Guide | google-html-css.md |
| Developer-facing docs you publish | Google developer documentation style guide | google-developer-docs.md |
| Web app UI copy | Web style layer | web.md |
| Installed / Apple-like UI | Apple HIG | apple-hig.md |

When two guides collide, pick the surface first. An iOS home-screen PWA uses Apple writing. A reference page in this repo uses Google-for-docs.
